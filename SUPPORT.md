# Support

LADING is maintained by an individual. Support is best-effort.

## How to get help

1. Read [README.md](README.md), [DISCLAIMER.md](DISCLAIMER.md), and
   [SECURITY.md](SECURITY.md).
2. Search existing GitHub issues for duplicates.
3. Open a GitHub issue with a minimal, deterministic reproduction (fixture
   binary + expected vs actual verdict/evidence when applicable).

## What is not support

- Legal advice or “will this satisfy my CRA / technical file” opinions
- Requests to soften kill tests or emit prove-a-negative VEX justifications
- Guarantees of completeness for any scanner CVE list

## Security

See [SECURITY.md](SECURITY.md). Do not file public issues for vulnerabilities.
