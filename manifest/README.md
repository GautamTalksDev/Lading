# Manifest data tree

Versioned Lading Manifest YAML lives here. See [SPEC-MANIFEST.md](../SPEC-MANIFEST.md)
for the contributor schema guide.

- `VERSION` — Manifest release semver
- `schema/entry.schema.json` — normative JSON Schema (fail closed)
- `components/` — promoted definitive entries only
- `candidates/` — derive output (`probable` only); never auto-promoted
- `COVERAGE.md` — generated by `lading manifest coverage` (do not edit by hand)
